# Neuron reference images

Ames's own neuron pictures, kept for use anywhere in Pyr (Ames 2026-11-20:
"you can add all these as neuron reference images"). Resized to 1600 px at
most from her originals.

- `eyewire-ii-retina-layers.jpg`: EyeWire II retina cells in their layers, on light grey.
- `pyramidal-neurons.jpg`: pyramidal neurons up close. Ames's caption: "the moment I saw our first connectomics Nature cover".
- `spot-the-mergers.jpg`: a dense tangle of cortical neurons, one picked out in green (a "spot the mergers" game image).
- `pyramidal-concept-ui.jpg`: a pyramidal neuron with a sci-fi info card ("PYRAMIDAL, Layer 3"), a concept for Pyr's UI.
