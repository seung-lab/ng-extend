The Challenge

Connectomics Proofreading at Scale

🧩

The Problem

Automated segmentation of brain volumes produces millions of neurons, but errors remain. Proofreading requires expert humans reviewing 3D data — a massive coordination challenge.

🚀

Our Solution

Transform neuroglancer into a community-powered proofreading platform with gamification, task management, real-time collaboration, and progress tracking — inspired by the original EyeWire.

Deep Dive

Tech Stack Breakdown

🖼️ Vue 3 + Composition API

19 single-file components (.vue) using <script setup> with TypeScript. Reactive UI injected into neuroglancer's DOM via createApp().mount() targeting NG container elements. Components range from full panels (Leaderboard, Brain Quest, User Profile) to micro-widgets (Achievement Toast, Confetti Celebration).

SplitMergeOverlay BrainQuestPanel Leaderboard ActivityFeed CommandPalette UserProfile WeeklyRecap Login

🧠 12 Pinia Stores

Centralized state management — each store owns a domain of data and logic. Reactive refs auto-sync to the UI. Several stores persist to localStorage for offline-first behavior.

splitMergeOverlay — tool state, points, results
proofreadingQueue — Brain Quest items, lineage
proofreadingBackend — Supabase CRUD, feed
cellHistory — segment nav, jump-to-cell
userStats — edits, streaks, badges
userPrefs — theme, settings, toggles
layers / volumes — dataset & layer mgmt
login / helpRequests / segAnnotation

⚡ esbuild Bundler

Blazing-fast builds in ~1 second. Custom build script (build-prod.js) with --define flags for compile-time config (Supabase keys, dataset tables, feature flags). Output: single minified JS bundle injected as a Chrome extension content script.

Dev mode: npm run dev-server with live reload via esbuild's serve API. Supports dataset override: DATASET=flywire_sandbox

🔌 Extension Architecture

Chrome extension injects into neuroglancer pages. MutationObserver watches for NG DOM changes (tool panels, segments, layers). 500ms polling (scanToolState) detects graphene tool activation. Custom keybindings (C, M, G, Esc, Enter) intercept NG events for the overlay.

11 widget services handle DOM injection, badge rendering, PCG queries, segment management, and annotation tools.

Core Features

Split & Merge Tooling

  • Split Mode (C) — Multicut with red/blue point groups, group swap (G), visual point counters
  • Merge Mode (M) — Ctrl+Click point placement, Enter-to-submit, inline status feedback
  • Holographic UI — Sci-fi materialization/exit animations, scanline overlays, edge glow
  • Real-time feedback — Loading spinners, success celebrations, error messages with retry hints
  • Combo counter — Tracks consecutive successful operations with escalating messages
  • Keyboard-first — C/M to activate, Esc to cancel, Enter to submit, G to swap groups
  • Error recovery — Status bar scraping catches NG errors, displays in overlay
  • Segment tracking — Watches visibleSegments.changed signal for merge/split detection
  • Edit statistics — Every operation logged: merge/split counts, coordinates, segment IDs
  • Supabase logging — segment_before/segment_after pairs for full audit trail

Task Management

🧠 Brain Quest

Daily Quests

3 cells per day selected from the Google Sheet queue. Seed-based randomization ensures everyone gets unique daily tasks. Full list mode available.

Progress Tracking

Per-cell: soma coordinates, final segment ID, annotation notes. Local edits persist across sessions. Proofread/pending status for each cell.

Cell Completion

First-time confirmation explains what "completing a cell" means. Big celebration animation with expanding rings and particle burst on completion.

Segment Lineage

When splits/merges create new segment IDs, they're automatically associated with the original quest cell. Navigate away and back — derived segments reload.

Auto-Navigation

Clicking a quest item sets viewer position and loads the segment into the segmentation layer. Works with soma coords, nuc coords, or position override.

Google Sheets Backend

Loads quest data from any published Google Sheet CSV. Default: Pinky v3 training sheet. Supports write-back for soma coordinates.

Data

Supported Datasets

🐭 Pinky (Default)

IARPA MICrONS Pinky — mouse visual cortex. Graphene segmentation with pinky_training3 table. Current focus for community proofreading.

🐭 Minnie65

IARPA MICrONS Minnie — 65-column mouse visual cortex. Public v117 segmentation table. Extensive ground truth available.

🪰 FlyWire

FAFB whole-brain Drosophila dataset. Sandbox environment for testing. Full connectome available.

🧬 Extensible

Any Graphene-backed dataset can be loaded via Available Volumes. Brain Quest works with any Google Sheet queue.

Infrastructure

Backend & API Integration

Supabase (6 Tables)

  • users — profiles, stats, streaks, flags, bios
  • edit_log — merge/split audit trail with segment IDs & coordinates
  • activity_feed — real-time community events via RealtimeDB
  • proofreading_tasks — centralized task assignment with priority
  • task_assignments — user locks with 30-min heartbeat renewal
  • help_requests — peer assistance tracking per segment

External APIs

  • CAVE API — Cell annotation (complete status, cell type), via MiddleAuth
  • PCG (PyChunkedGraph) — Segment change logs for merge/split history
  • Google Sheets — CSV export for Brain Quest queues, optional write-back
  • Neuroglancer Viewer — Layer management, navigation, segment selection

Offline-first: All stats, history, preferences, and edits persist in localStorage. Backend sync is additive, never blocking.
